# vendor/omix/X2034

Proprietary files for **OMIX X2034** (MT6835), extracted read-only from the
stock Android 13 vendor stack. The running system at dump time was a
LineageOS 23.2 GSI; `/vendor` and `/vendor_dlkm` were the stock partitions.

## Contents
- `proprietary/vendor/` — `/vendor` (3,308 files, 781 symlinks)
- `proprietary/vendor_dlkm/` — `/vendor_dlkm` (190 files)
- `proprietary/odm_dlkm/` — `/odm_dlkm` (5 files)
- `Android.bp` — 1,825 Soong modules (ELF libs/bins/scripts)
- `Android.mk` — creates `/vendor/lib/modules -> /vendor_dlkm/lib/modules`
- `X2034-vendor.mk` — `PRODUCT_PACKAGES` + 1,675 `PRODUCT_COPY_FILES`
- `vendor_properties.mk` — 594 props imported from stock `/vendor/build.prop`
- `proprietary-files.txt` — human-readable extraction manifest
- `BoardConfigVendor.mk`

## MediaTek symlink normalization
Stock MTK puts real ELF files under `lib*/mt6835/`, `bin*/mt6835/` and exposes
them through top-level symlinks. The generator installs the real files at the
symlink names (the loader-facing paths) and does **not** install the `mt6835/`
directories. This was checked against the binaries and init/config files:
there are no hardcoded `/vendor/*/mt6835/` references.

Same-directory aliases (e.g. the 175 `toybox_vendor` applets and the two
`/vendor/bin/hw` absolute aliases) are emitted as Soong `symlinks`.

## Generation
The tree was generated by `dump/gen_vendor.py` after verifying every file
against the device with SHA-256. To refresh the blobs, use
`device/omix/X2034/extract-files.sh`.

## Build notes
- Use EROFS/LZ4 for `vendor`, `vendor_dlkm`, `odm_dlkm` and `system_dlkm`.
  The 1.0 GB vendor tree does not fit the 666 MB stock vendor partition as
  ext4; stock is EROFS and fits.
- `vendor/build.prop` is not copied; its non-system properties are imported
  into `vendor_properties.mk` (including `ro.vndk.version=33`). The
  `vendor_dlkm`/`odm_dlkm` identity `build.prop` files are generated by the
  platform.
- `/vendor/lib/modules -> /vendor_dlkm/lib/modules` and
  `/vendor/etc/mdota` are created at install time by `Android.mk`.
